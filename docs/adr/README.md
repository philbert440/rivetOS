# Architecture decision records

This directory is the home for short, dated ADRs.

Product decisions have lived in `docs/ARCHITECTURE.md`, `docs/LOCAL-MODE.md`,
and related guides. Write an ADR when a choice is expensive to reverse
(harness IDs, license boundaries, install-path env vars, boot vs discovery).

A markdown file with Context / Decision / Consequences is enough. Do not
adopt an ADR SaaS or a heavy template.
