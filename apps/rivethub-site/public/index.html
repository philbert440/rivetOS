Before you start

A few useful answers.

What is RivetHub?

RivetHub is a distribution of the open-source RivetOS runtime. It gives you a private, local hub for capturing, organizing, and retrieving agent sessions, tool calls, and outputs across supported integrations.

Which agent tools can I connect?

Local setup detects Claude Code, Codex, Grok Build, Kimi Code, and Hermes. Capture and recall depend on the integration being connected and the local node running. Review the integration guide and verify your first captured session.

Does all processing stay on my machine?

The collection is stored locally. Your chosen agent providers still process the prompts you send them. Optional embedding and compaction services process the content sent to them; local services and cloud services have different data boundaries.

Do I need an embedding model to start?

No. Full-text and fuzzy search work without one. Semantic search uses an optional embedding endpoint you can configure on the server today. Embedding and compaction models are already server options; changing them from the desktop app is planned.

Can I use my collection for model training?

Your captured work is a foundation for training and evaluation datasets. Guided curation and training-ready exports are planned. The current installer does not provide a one-click SFT or model-training pipeline.

Can I run the hub on Windows?

The local installer supports Linux and macOS. The Windows desktop app connects to an existing hub. On macOS, use the browser; the macOS desktop app is coming later.
