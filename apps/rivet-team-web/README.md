# @rivetos/rivet-team-web

OpenMausBot's frontend (`src/omb/`, MIT, taken from milind-soni/OpenMausBot)
wired to the rivet-team gateway. Chat list/select/send do not use their
harness server. Faces are Rivet den-bot (`src/omb/components/Avatar.tsx`).

Household identity (`UserGate`) stays in front of their App shell.

See `src/omb/ORIGIN.md`.
